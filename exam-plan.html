Move your ATK/DEF parsing into a Stats record:

public record Stats(int attack, int defence, int health, int speed) {

    /**
     * Reads the stats from a line of the file.
     *
     * @param line a line such as "3ATK - 1DEF - 15HP - 4SPD"
     * @return the stats on that line
     */
    public static Stats parse(String line) {
        String[] parts = line.split(" - ");
        return new Stats(Integer.parseInt(parts[0].replace("ATK", "")),
                Integer.parseInt(parts[1].replace("DEF", "")),
                Integer.parseInt(parts[2].replace("HP", "")),
                Integer.parseInt(parts[3].replace("SPD", "")));
    }
}

Move your strengths and weaknesses loop into a Traits record:

public static Traits parse(String line) {
    List<String> strengths = new ArrayList<>();
    List<String> weaknesses = new ArrayList<>();
    Scanner scanner = new Scanner(line);
    scanner.useDelimiter(" - ");
    while (scanner.hasNext()) {
        String[] trait = scanner.next().split(": ");
        if (trait[0].equals("strength")) {
            strengths.add(trait[1]);
        } else {
            weaknesses.add(trait[1]);
        }
    }
    return new Traits(strengths, weaknesses);
}

Now readMech becomes three short lines. readEquipment uses Traits.parse in the same way.

public static Mech readMech(Scanner scanner) {
    String[] line1 = scanner.nextLine().split(" - ");
    Stats stats = Stats.parse(scanner.nextLine());
    Traits traits = Traits.parse(scanner.nextLine());
    return new Mech(line1[1], line1[2], Integer.parseInt(line1[3]), stats, traits);
}

public Traits combinedWith(Traits other) {
    List<String> allStrengths = new ArrayList<>(strengths);
    allStrengths.addAll(other.strengths());
    List<String> allWeaknesses = new ArrayList<>(weaknesses);
    allWeaknesses.addAll(other.weaknesses());
    return new Traits(
            allStrengths.stream().filter(x -> !allWeaknesses.contains(x)).toList(),
            allWeaknesses.stream().filter(x -> !allStrengths.contains(x)).toList());
}

Write the combat rules

10 min

This is the biggest task in the exam. Write one attack first, then the loop. Health is kept in local variables, so nothing needs resetting after the fight.

One attack follows the exam's four steps. Math.max stops the damage from going below 0.

public static int damage(Fighter attacker, Fighter defender) {
    int attack = attacker.totalAttack();
    if (attacker.traits().hasAdvantageOver(defender.traits())) {
        attack *= 2;
    }
    return Math.max(0, attack - defender.totalDefence());
}

The loop swaps turns until someone reaches 0. The player starts on a speed draw because of >=.

public static boolean playerWins(Fighter player, Fighter mech) {
    int playerDamage = damage(player, mech);
    int mechDamage = damage(mech, player);
    if (playerDamage == 0 && mechDamage == 0) {
        return false;
    }
    int playerHealth = player.health();
    int mechHealth = mech.health();
    boolean playerTurn = player.speed() >= mech.speed();
    while (playerHealth > 0 && mechHealth > 0) {
        if (playerTurn) {
            mechHealth -= playerDamage;
        } else {
            playerHealth -= mechDamage;
        }
        playerTurn = !playerTurn;
    }
    return mechHealth <= 0;
}

My assumption: the exam doesn't say what happens if neither side can do damage. Without the early return false, that battle would never end, so I count it as a loss.

Collection.javasrc
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;
import java.util.Scanner;
import java.util.stream.Collectors;

/**
 * Stores the mechs, the equipment and the player, and runs the game.
 */
public class Collection {
    private final List<Mech> mechs = new ArrayList<>();
    private final List<Equipment> equipments = new ArrayList<>();
    private final Player player = new Player();
    private int battlesWon;

    /**
     * Reads all mechs and equipment.
     *
     * @param scanner the scanner on the file
     */
    public void readFromFile(Scanner scanner) {
        int mechNumber = Integer.parseInt(scanner.nextLine().trim());
        for (int i = 0; i < mechNumber; i++) {
            mechs.add(Mech.readMech(scanner));
        }
        int equipmentNumber = Integer.parseInt(scanner.nextLine().trim());
        for (int i = 0; i < equipmentNumber; i++) {
            equipments.add(Equipment.readEquipment(scanner));
        }
    }

    /**
     * Creates the text for option 1.
     *
     * @return all mechs, separated by empty lines
     */
    public String mechsText() {
        return mechs.stream().map(Mech::toString).collect(Collectors.joining("\n\n"));
    }

    /**
     * Creates the text for option 2.
     *
     * @return the stats and equipment of the player
     */
    public String playerText() {
        return player.toString();
    }

    /**
     * Fights the next mech, starting again at the first mech after the last one.
     *
     * @return the outcome of the fight
     */
    public String fightNextMech() {
        if (mechs.isEmpty()) {
            return "There are no mechs to fight.";
        }
        Mech mech = mechs.get(battlesWon % mechs.size());
        String start = "You fight against a " + mech.getName() + "... ";
        if (!Battle.playerWins(player, mech)) {
            player.reset();
            battlesWon = 0;
            return start + "and lose. Game over, your player has been reset.";
        }
        battlesWon++;
        Equipment loot = findEquipment(mech.getLootDropID());
        player.equip(loot);
        return start + "and win! You get a " + loot.getName() + ".\n"
                + "You have won " + battlesWon + " battles.";
    }

    /**
     * Finds a piece of equipment by its ID.
     *
     * @param id the ID to look for
     * @return the equipment
     * @throws IllegalArgumentException if no equipment has this ID
     */
    private Equipment findEquipment(int id) {
        return equipments.stream()
                .filter(equipment -> equipment.getEquipmentID() == id)
                .findFirst()
                .orElseThrow(() -> new IllegalArgumentException("Unknown equipment: " + id));
    }

    /**
     * Creates the text that is saved in option 4.
     *
     * @return the battles won and the ID of the equipment in each slot
     */
    public String stateText() {
        return "battles: " + battlesWon + "\n"
                + "offensive: " + idOf(player.getOffensiveEquipment()) + "\n"
                + "defensive: " + idOf(player.getDefensiveEquipment());
    }

    /**
     * Writes the ID of the equipment in a slot.
     *
     * @param equipment the equipment in the slot, which can be null
     * @return the ID, or "none" for an empty slot
     */
    private String idOf(Equipment equipment) {
        return equipment == null ? "none" : String.valueOf(equipment.getEquipmentID());
    }

    /**
     * Restores the game from the text that option 4 saved.
     *
     * @param scanner the scanner on the saved text
     */
    public void restoreState(Scanner scanner) {
        battlesWon = Integer.parseInt(valueOf(scanner.nextLine()));
        player.reset();
        restoreSlot(valueOf(scanner.nextLine()));
        restoreSlot(valueOf(scanner.nextLine()));
    }

    /**
     * Reads the value from a saved line.
     *
     * @param line a line such as "battles: 2"
     * @return the part after the colon
     */
    private String valueOf(String line) {
        return line.split(": ")[1].trim();
    }

    /**
     * Equips the equipment with this ID, unless the slot was empty.
     *
     * @param id the saved ID, or "none"
     */
    private void restoreSlot(String id) {
        if (!id.equals("none")) {
            player.equip(findEquipment(Integer.parseInt(id)));
        }
    }

Battle.javasrc
/**
 * The combat rules. All methods are static, so this class does not need
 * equals and hashCode.
 */
public class Battle {

    /**
     * Calculates the damage of one attack.
     *
     * @param attacker the side that attacks
     * @param defender the side that defends
     * @return the health points the defender loses, which is never below 0
     */
    public static int damage(Fighter attacker, Fighter defender) {
        int attack = attacker.totalAttack();
        if (attacker.traits().hasAdvantageOver(defender.traits())) {
            attack *= 2;
        }
        return Math.max(0, attack - defender.totalDefence());
    }

    /**
     * Plays a whole battle. The fastest side starts, and the player starts on a draw.
     * If neither side can do damage, the exam gives no winner, so this counts as a loss
     * to stop the battle from never ending.
     *
     * @param player the player
     * @param mech the mech
     * @return true if the player wins
     */
    public static boolean playerWins(Fighter player, Fighter mech) {
        int playerDamage = damage(player, mech);
        int mechDamage = damage(mech, player);
        if (playerDamage == 0 && mechDamage == 0) {
            return false;
        }
        int playerHealth = player.health();
        int mechHealth = mech.health();
        boolean playerTurn = player.speed() >= mech.speed();
        while (playerHealth > 0 && mechHealth > 0) {
            if (playerTurn) {
                mechHealth -= playerDamage;
            } else {
                playerHealth -= mechDamage;
            }
            playerTurn = !playerTurn;
        }
        return mechHealth <= 0;
    }
}

Traits.javasrc
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

/**
 * The strengths and weaknesses of a mech, a piece of equipment or the player.
 *
 * @param strengths the elements this is strong in
 * @param weaknesses the elements this is weak against
 */
public record Traits(List<String> strengths, List<String> weaknesses) {

    /**
     * Reads the traits from a line of the file. The line can be empty.
     *
     * @param line a line such as "strength: ice - weakness: fire"
     * @return the traits on that line
     */
    public static Traits parse(String line) {
        List<String> strengths = new ArrayList<>();
        List<String> weaknesses = new ArrayList<>();
        Scanner scanner = new Scanner(line);
        scanner.useDelimiter(" - ");
        while (scanner.hasNext()) {
            String[] trait = scanner.next().split(": ");
            if (trait[0].equals("strength")) {
                strengths.add(trait[1]);
            } else {
                weaknesses.add(trait[1]);
            }
        }
        return new Traits(strengths, weaknesses);
    }

    /**
     * Checks whether one of these strengths matches a weakness of the other side.
     *
     * @param other the traits of the other side
     * @return true if at least one element matches
     */
    public boolean hasAdvantageOver(Traits other) {
        return strengths.stream().anyMatch(other.weaknesses()::contains);
    }

    /**
     * Adds other traits to these. An element that ends up as both a strength and a
     * weakness cancels out.
     *
     * @param other the traits to add
     * @return the combined traits
     */
    public Traits combinedWith(Traits other) {
        List<String> allStrengths = new ArrayList<>(strengths);
        allStrengths.addAll(other.strengths());
        List<String> allWeaknesses = new ArrayList<>(weaknesses);
        allWeaknesses.addAll(other.weaknesses());
        return new Traits(
                allStrengths.stream().filter(x -> !allWeaknesses.contains(x)).toList(),
                allWeaknesses.stream().filter(x -> !allStrengths.contains(x)).toList());
    }

    /**
     * Describes the traits in a readable way.
     *
     * @return the strengths and weaknesses, using "none" for an empty list
     */
    @Override
    public String toString() {
        return "strength(s): " + listText(strengths) + ", weakness(es): " + listText(weaknesses);
    }

    /**
     * Writes a list as text.
     *
     * @param values the values to write
     * @return the values separated by commas, or "none" for an empty list
     */
    private static String listText(List<String> values) {
        return values.isEmpty() ? "none" : String.join(", ", values);
    }
}

import static org.junit.jupiter.api.Assertions.assertNotEquals;
import static org.junit.jupiter.api.Assertions.assertTrue;

class ReadingTest {
    private static final Traits NONE = new Traits(List.of(), List.of());

    /**
     * Tests all values of a mech, and its equals and hashCode.
     */
    @Test
    void testReadMech() {
        Mech mech = Mech.readMech(new Scanner("""
                MECH - Howler - Delta - 29845
                2ATK - 2DEF - 24HP - 3SPD
                strength: fire
                """));
        Mech expected = new Mech("Howler", "Delta", 29845, new Stats(2, 2, 24, 3),
                new Traits(List.of("fire"), List.of()));
        assertEquals(expected, mech);
        assertEquals(expected.hashCode(), mech.hashCode());
    }

    /**
     * Tests that mechs with different data are not equal.
     */
    @Test
    void testMechNotEquals() {
        Stats stats = new Stats(1, 1, 1, 1);
        Mech mech = new Mech("A", "B", 1, stats, NONE);
        assertFalse(mech.equals(null));
        assertNotEquals(mech, new Mech("X", "B", 1, stats, NONE));
        assertNotEquals(mech, new Mech("A", "X", 1, stats, NONE));
        assertNotEquals(mech, new Mech("A", "B", 2, stats, NONE));
        assertNotEquals(mech, new Mech("A", "B", 1, new Stats(2, 1, 1, 1), NONE));
    }

    /**
     * Tests the readable text of a mech.
     */
    @Test
    void testMechToString() {
        Mech mech = new Mech("Howler", "Delta", 1, new Stats(2, 2, 24, 3),
                new Traits(List.of("fire"), List.of()));
        String expected = "Howler (Category Delta)\n"
                + "It has 2 attack, 2 defence, 24 health, and 3 speed.\n"
                + "strength(s): fire, weakness(es): none";
        assertEquals(expected, mech.toString());
    }

    /**
     * Tests offensive equipment, with an empty traits line and a misspelled first word.
     */
    @Test
    void testReadOffensiveEquipment() {
        Equipment equipment = Equipment.readEquipment(new Scanner("""
                EQUIMENT - Rusted Spear - Offensive - 13568
                1ATK

                """));
        assertEquals(new Equipment("Rusted Spear", "Offensive", 13568, 1, 0, NONE), equipment);
        assertTrue(equipment.isOffensive());
    }

    /**
     * Tests defensive equipment.
     */
    @Test
    void testReadDefensiveEquipment() {
        Equipment equipment = Equipment.readEquipment(new Scanner("""
                EQUIPMENT - Leather Armor - Defensive - 43564
                1DEF
                weakness: wind
                """));
        assertEquals(1, equipment.getDefenceBonus());
        assertFalse(equipment.isOffensive());
    }

    /**
     * Tests equals and hashCode of equipment.
     */
    @Test
    void testEquipmentEquals() {
        Equipment equipment = new Equipment("A", "Offensive", 1, 2, 0, NONE);
        Equipment same = new Equipment("A", "Offensive", 1, 2, 0, NONE);
        assertEquals(equipment.hashCode(), same.hashCode());
        assertFalse(equipment.equals(null));
        assertNotEquals(equipment, new Equipment("X", "Offensive", 1, 2, 0, NONE));
        assertNotEquals(equipment, new Equipment("A", "Defensive", 1, 2, 0, NONE));
        assertNotEquals(equipment, new Equipment("A", "Offensive", 9, 2, 0, NONE));
        assertNotEquals(equipment, new Equipment("A", "Offensive", 1, 9, 0, NONE));
        assertNotEquals(equipment, new Equipment("A", "Offensive", 1, 2, 9, NONE));
    }
}

import org.junit.jupiter.api.Test;

import java.util.List;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertFalse;
import static org.junit.jupiter.api.Assertions.assertTrue;

class TraitsTest {

    /**
     * Tests a line with one strength and two weaknesses.
     */
    @Test
    void testParse() {
        Traits traits = Traits.parse("strength: ice - weakness: fire - weakness: acid");
        assertEquals(new Traits(List.of("ice"), List.of("fire", "acid")), traits);
    }

    /**
     * Tests that an empty line gives empty lists.
     */
    @Test
    void testParseEmptyLine() {
        assertEquals(new Traits(List.of(), List.of()), Traits.parse(""));
    }

    /**
     * Tests that a strength only helps against a matching weakness.
     */
    @Test
    void testHasAdvantageOver() {
        Traits fire = new Traits(List.of("fire"), List.of());
        assertTrue(fire.hasAdvantageOver(new Traits(List.of(), List.of("fire"))));
        assertFalse(fire.hasAdvantageOver(new Traits(List.of(), List.of("ice"))));
    }

    /**
     * Tests that an element that is both a strength and a weakness cancels out.
     */
    @Test
    void testCombinedWithCancelsOut() {
        Traits first = new Traits(List.of("acid", "fire"), List.of());
        Traits second = new Traits(List.of(), List.of("acid", "wind"));
        assertEquals(new Traits(List.of("fire"), List.of("wind")), first.combinedWith(second));
    }

    /**
     * Tests the readable text, including an empty list.
     */
    @Test
    void testToString() {
        Traits traits = new Traits(List.of("wind", "ice"), List.of());
        assertEquals("strength(s): wind, ice, weakness(es): none", traits.toString());
    }
}

import org.junit.jupiter.api.Test;

import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;

import static org.junit.jupiter.api.Assertions.assertTrue;

class MainTest {

    /**
     * Runs the menu with typed answers. The exam does not require this test, but it
     * raises the coverage. It saves mech_state.txt in the working directory.
     *
     * @throws IOException if the temporary file cannot be used
     */
    @Test
    void testMenu() throws IOException {
        Path cars = Files.createTempFile("mechs", ".txt");
        Files.writeString(cars, """
                1
                MECH - Howler - Delta - 29845
                2ATK - 2DEF - 24HP - 3SPD
                strength: fire
                1
                EQUIPMENT - Power Armor - Defensive - 29845
                3DEF
                strength: fire
                """);
        Files.deleteIfExists(Path.of("mech_state.txt"));
        String answers = "missing.txt\n" + cars + "\n5\n1\n2\n3\n4\n5\n9\n6\n";

        InputStream normalIn = System.in;
        PrintStream normalOut = System.out;
        ByteArrayOutputStream printed = new ByteArrayOutputStream();
        System.setIn(new ByteArrayInputStream(answers.getBytes()));
        System.setOut(new PrintStream(printed));
        Main.main(new String[0]);
        System.setIn(normalIn);
        System.setOut(normalOut);

        String output = printed.toString();
        assertTrue(output.contains("File not found"));
        assertTrue(output.contains("There is no saved state yet."));
        assertTrue(output.contains("You get a Power Armor."));
        assertTrue(output.contains("State restored."));
        assertTrue(output.contains("Not a correct option."));
        Files.delete(cars);
        Files.deleteIfExists(Path.of("mech_state.txt"));
    }
}
