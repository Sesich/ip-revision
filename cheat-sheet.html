Rules that cost points

top ↑

Exam grading (mock exam)

  1. Compiles — otherwise 0 points
  2. Class design (inheritance, interfaces, composition)
  3. IO (reading / writing files)
  4. Data processing
  5. Tests
  6. Code style

Allowed: IntelliJ, slides, Javadoc, offline "Answers EWI". No notes, no internet.

БГАко кодът не се компилира — 0 точки за цялата задача. Компилирай след всеки няколко реда.

Compiling

  • Checked exceptions → catch or throws
  • String: length(), charAt(i) · array: .length · List: size(), get(i)
  • split → String[], not List
  • static method → no this, no instance fields

Streams & threads

  • No terminal operation → nothing runs. One stream = one use.
  • count() → long · sum() only on IntStream · max/findFirst/average → Optional
  • Method returns Stream → no toList() at the end
  • Runnable alone starts nothing. Thread.ofPlatform().start(r) → new thread runs r.run()
  • Thread order never guaranteed · shared data → synchronized

Equality

  • == on objects = same address. Use equals (also for Strings)
  • hashCode uses the same fields as equals
  • arrays → Arrays.equals · order doesn't matter → HashSet
  • getClass() in equals, not instanceof

Memory & types

  • Objects + all arrays on the heap; variables hold references
  • Method can change the object, not the caller's variable
  • Autoboxing = primitive → wrapper by Java. Integer ≠ Double
  • Overloading = static binding · overriding = dynamic binding
  • Wrong downcast compiles, then ClassCastException

Tests, exceptions, IO

  • Test stops at first failed assert · assertEquals(expected, actual)
  • assertThrows(X.class, () -> …) passes when X is thrown
  • CC = conditions of if/while/for + 1 (if (a || b) counts once)
  • throws doesn't stop an exception, only catch does
  • int/0 throws, double/0 = Infinity, overflow wraps
  • nextDouble() uses locale, Double.parseDouble needs a dot

Process vs thread

Process Thread
Is a running program a line of execution inside a process
Memory own, private shared with the process
Count many per computer many per process; 1 process per thread

Every Java program starts with the main thread.

БГПроцесът е програма със собствена памет. Нишката е „линия на изпълнение“ вътре в процеса и споделя паметта му. Една нишка принадлежи на точно един процес.

Concurrency vs parallelism

  • Concurrency: many things at the same time
  • Parallelism: one big job split over processors
Hardware What happens
1 core interleaving: threads take turns, order not fixed
> 1 core truly in parallel
hyperthreading state parts duplicated, execution units not

Heisenbug: bug from wrong expectations about scheduling; appears and disappears. Use threads for easily split work: web servers, converting many files, input while loading.

БГConcurrency е възможно и на едно ядро — нишките просто се редуват (interleaving).

Create and start

public class Task implements Runnable {
    public void run() { System.out.println("working"); }
}

Thread t = Thread.ofPlatform().start(new Task());   // new thread runs run()
Thread.ofVirtual().start(new Task());
Thread.ofVirtual().start(() -> System.out.println("hi"));  // Runnable is functional
new Thread(new Task()).start();                     // classic way
t.join();                                           // wait until t is done

try { Thread.sleep(1000); }                         // checked InterruptedException
catch (InterruptedException e) { }                  // must catch inside run()

You write Result

БГНишката вижда обекта само като Runnable, а Runnable има само run(). Затова твой метод start() никога не се извиква (задачата с RoadRunner).

Race condition

x = 0, 2 threads each do a = x; a = a + 1; x = a; 10 times.

T1 T2 x
reads 0 0
reads 0 0
writes 1 1
writes 1 1 (lost update)

Result: ≤ 20, never more, never < 0, not predictable. Order of threads is decided by the scheduler and differs per OS and per run.

БГx++ е три стъпки: чети, добави, запиши. Ако две нишки прочетат една и съща стойност, едното увеличение се губи.

synchronized

public synchronized void increment() { c++; }   // whole method
public void decrement() {
    synchronized (this) { c--; }                // only this block
}

Per object: while one thread is in a synchronized method of o, no other thread can enter any synchronized method of o. Other objects and non-synchronized methods are not blocked.

БГКлючалката е на обекта, не на класа. Две различни инстанции не се блокират взаимно.

Deadlock

  • T1 in synchronized o1.m1() → calls synchronized o2.m3() → waits for o2
  • T2 in synchronized o2.m2() → calls synchronized o1.m4() → waits for o1
  • Both wait forever.

Avoid: lock objects in the same order everywhere, keep synchronized code short.

БГDeadlock: всяка нишка държи ключалката, която другата чака. Двете чакат вечно.

enum

public enum CardType {
    NORMAL("white"), RARE("blue"), EPIC("purple"), LEGENDARY("gold");
    private final String colour;
    CardType(String colour) { this.colour = colour; }   // always private
    public String getColour() { return colour; }
}

values() · valueOf("RARE") · EPIC.ordinal() = 2 · RARE.compareTo(EPIC) < 0 (declaration order) · == is safe

switch

// statement: needs break, falls through without it
switch (type) {
    case NORMAL, RARE: msg = "normal"; break;
    default: msg = "other";
}
// expression: returns a value, no break, ; at the end
String msg = switch (type) {
    case NORMAL, RARE, EPIC -> "nothing special";
    case LEGENDARY -> "a legendary!";
};

Works on int/char/… , String, enums.

БГПри switch expression (->) няма fall-through и break. default не е нужен, ако всички случаи на enum-а са покрити.

sealed / final

public sealed class Shape permits Circle, Square { }
public final class Circle extends Shape { }       // no subclasses
public non-sealed class Square extends Shape { } // open again

БГРазликата със final: sealed позволява някои изброени подкласове, final — никакви. Точно това търсеха в отворения въпрос.

Exceptions

top ↑

Hierarchy

Throwable
├── Error              don't catch: OutOfMemoryError, StackOverflowError
└── Exception          CHECKED: IOException, FileNotFoundException,
    │                           InterruptedException, ClassNotFoundException
    └── RuntimeException   UNCHECKED: NullPointer, Arithmetic, ClassCast,
                           IndexOutOfBounds, NumberFormat, IllegalArgument

БГChecked = компилаторът те кара да я хванеш (catch) или да я декларираш (throws). Unchecked = наследява RuntimeException, не е задължително.

Causes

Exception Example
NullPointerException null.length()
ArithmeticException 10 / 0 (int)
ArrayIndexOutOfBounds… a[3] on length 3
StringIndexOutOfBounds… "abc".charAt(3)
NegativeArraySize… new int[-1]
ClassCastException (String) someInteger
NumberFormatException Integer.parseInt("abc")
StackOverflowError endless recursion

Not exceptions: int overflow (wraps), 5.0 / 0 = Infinity, 0.0 / 0 = NaN.

try / catch / finally

try {
    int i = Integer.parseInt(text);   // throws → jump to catch
} catch (NumberFormatException e) {   // specific BEFORE general
    System.out.println(e.getMessage());
} finally {
    // always runs, even after return: close files, locks
}

catch (Exception) before catch (IOException) → compile error. Not caught anywhere → default exception handler: stack trace, program ends.

throws & own exceptions

public void read() throws IOException { … }      // pass it to the caller

public class DivByZeroException extends Exception {   // checked
    public DivByZeroException(String s) { super(s); }
}
if (d == 0) throw new DivByZeroException("Divisor cannot be zero");

Override may throw the same or narrower checked exceptions, never broader.

БГthrows не спира изключението — само го подава нагоре. Спира го само catch.

File template

public static List<Shelter> read(String path) throws FileNotFoundException {
    List<Shelter> result = new ArrayList<>();
    Scanner sc = new Scanner(new File(path));
    while (sc.hasNextLine()) {
        Scanner line = new Scanner(sc.nextLine());  // "Coastal A.1 470 False 40"
        String type = line.next();
        String id = line.next();
        int volume = line.nextInt();
        boolean free = line.nextBoolean();
        switch (type) {
            case "Coastal" -> result.add(new CoastalShelter(id, volume, free, line.nextInt()));
            case "Tundra"  -> result.add(new TundraShelter(id, volume, free));
            case "Reef"    -> result.add(new ReefShelter(id, volume, free, line.nextInt()));
        }
    }
    sc.close();
    return result;
}
// "Penguin; 300; Tundra, Coastal"

equals + hashCode template

@Override
public boolean equals(Object o) {                       // Object, not TVStore!
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    TVStore that = (TVStore) o;
    return number == that.number                        // primitive: ==
            && Objects.equals(name, that.name)          // object: null-safe
            && Arrays.equals(tvs, that.tvs);            // array: contents
}
@Override
public int hashCode() {
    return 31 * Objects.hash(name, number) + Arrays.hashCode(tvs);
}
// order doesn't matter: new HashSet<>(list).equals(new HashSet<>(o.list))
// subclass: ... && super.equals(o)

БГhashCode трябва да ползва същите полета като equals. Равни обекти → задължително равни hashCode; обратното не е нужно.

equals contract

Property Rule
reflexive x.equals(x)
symmetric x.equals(y) ⇔ y.equals(x)
transitive x=y and y=z → x=z
consistent same answer again
non-null x.equals(null) is false

Without your own equals: Object.equals = == (addresses). assertEquals uses equals.

instanceof breaks symmetry

// Vehicle uses instanceof Vehicle, Train uses instanceof Train
vehicle.equals(train);   // true  (a Train is a Vehicle)
train.equals(vehicle);   // false (a Vehicle is not a Train)

With getClass() both are false → symmetric.

БГАко родителят ползва instanceof, а детето getClass() (или обратно), p.equals(s) може да е true, а s.equals(p) false — нарушена симетрия.

Records

public record Person(String name, int age) { } generates:

  • private final fields → immutable
  • constructor with all fields
  • accessors name(), age() — no get

Can: add methods, static fields, override equals, implement interfaces. Can't: extend a class, be extended, change fields.

Cyclomatic complexity

CC = conditions in if/while/for/… + 1

if ((x > 0) && (y > 0)) …        // 1
else if ((x < 0) && (y > 0)) …   // 2
else if ((x > 0) && (y < 0)) …   // 3
else …                           // CC = 4

БГКурсът брои всеки if като едно условие, дори да има &&/|| в него. +1 го има винаги — метод без if има CC = 1.
